Nº 007 — Setup

Configurar a conexão

Google Sheets + Apps Script v2.
1
Cole o Apps Script v2
No Sheets: Extensões → Apps Script. Apague tudo, cole o bloco abaixo e salve (Ctrl+S).
2
Rode as funções pelo botão ▶
No editor, ao lado de Executar, escolha a função pelo nome e clique em ▶ (autorize na 1ª vez):
criarAbaMetas() — cria a aba metas agora.
verificarInstalacao() — diagnóstico.
simularReclassificacao() — relatório, não altera nada.
aplicarReclassificacao() — aplica (faz backup antes).
Veja a saída em Registro de execução.
3
Reimplante — sem isto o app não salva metas
Implantar → Gerenciar implantações → ✏️ (lápis) → Versão: Nova versão → Implantar.
Só salvar o código não atualiza a URL /exec. Para conferir, abra a URL no navegador: deve responder FlashFinance API v2 OK. Se aparecer um JSON com os gastos, ainda é a v1.
