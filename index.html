SETUP
CONFIGURAR
Google Sheets + Apps Script — ~10 minutos
01
Crie o Google Sheets
Acesse sheets.google.com, crie uma planilha chamada FlashFinance.
Crie duas abas: gastos e receitas.

Na aba gastos, linha 1, cole os cabeçalhos:
ID Titulo Tipo Classe Metodo Valor Data Mes Parcela
Na aba receitas, linha 1:
ID Titulo Tipo Valor Data Mes
02
Cole o Apps Script
No Sheets: Extensões → Apps Script.
Apague o conteúdo existente, cole o código abaixo e salve com Ctrl+S.
function doPost(e) { try { var ss = SpreadsheetApp.getActiveSpreadsheet(); var data = JSON.parse(e.postData.contents); var tipo = data.tipo; var rows = data.rows; if (tipo === 'ping') return ContentService.createTextOutput('OK'); var sheet = ss.getSheetByName(tipo === 'gasto' ? 'gastos' : 'receitas'); if (!sheet) return ContentService.createTextOutput('SHEET_NOT_FOUND'); for (var i = 0; i < rows.length; i++) { sheet.appendRow(rows[i]); } return ContentService.createTextOutput('OK:' + rows.length); } catch(err) { return ContentService.createTextOutput('ERROR:' + err.toString()); } } function doGet(e) { return ContentService.createTextOutput('FlashFinance API OK'); }
03
Publique como Web App
No Apps Script: Implantar → Nova implantação.
Tipo: App da Web · Executar como: Eu · Acesso: Qualquer pessoa.
Clique Implantar, autorize e copie a URL gerada.
Ela tem o formato https://script.google.com/macros/s/.../exec
04
Cole a URL e teste
Depois de publicar, cole a URL aqui para conectar o formulário ao Sheets:
05
Conecte no Looker Studio
Com os dados no Sheets, acesse lookerstudio.google.com.
Criar → Relatório → adicione sua planilha FlashFinance como fonte de dados.

A partir daí é arrastar e soltar — gráficos de barra, rosca, tabelas, KPIs de meta.
Como você já usa BI no trabalho, vai dominar em menos de 30 minutos.
