Nº 007 — Setup

Configurar a conexão

Google Sheets + Apps Script v2.
1
Cole o Apps Script v2
No Sheets: Extensões → Apps Script. Apague tudo, cole o bloco abaixo e salve (Ctrl+S).
2
Rode as funções pelo botão ▶
No editor, ao lado de Executar, escolha a função pelo nome e clique em ▶ (autorize na 1ª vez):
criarAbaMetas() — cria a aba metas agora.
verificarInstalacao() — diagnóstico.
simularReclassificacao() — relatório, não altera nada.
aplicarReclassificacao() — aplica (faz backup antes).
Veja a saída em Registro de execução.
3
Reimplante — sem isto o app não salva metas
Implantar → Gerenciar implantações → ✏️ (lápis) → Versão: Nova versão → Implantar.
Só salvar o código não atualiza a URL /exec. Para conferir, abra a URL no navegador: deve responder FlashFinance API v2 OK. Se aparecer um JSON com os gastos, ainda é a v1.

Registro automático no iPhone (Atalhos + Carteira)
O mais perto de "o Nubank lança sozinho": toda compra por aproximação com o Nubank na Carteira dispara um atalho que pergunta a categoria (1 toque) e grava o gasto na planilha.
1. Copie o script do passo 1 de novo e reimplante (passo 3). A versão nova aceita ?acao=rapido.
2. Teste o seu link abaixo no navegador trocando os MAIÚSCULOS (ex.: titulo=Teste&valor=1,00&tipo=Outros). Deve responder OK:1. Depois apague a linha de teste na planilha.
3. No app Atalhos: Automação → Nova automação → Transação → escolha o cartão Nubank → Executar imediatamente.
4. Ações: Escolher do Menu (Alimentação, Transporte, Mercado, Social, Saúde, Outros) → Codificar URL no Comerciante → URL com o link abaixo, trocando TITULO pelo Comerciante, VALOR pela Quantia e CATEGORIA pelo item escolhido → Obter conteúdo do URL.
Os nomes das ações e variáveis podem variar um pouco conforme a versão do iOS (a automação "Transação" existe a partir do iOS 17).
O que fica de fora: Pix no crédito, compras online e cartão físico não passam pela Carteira, então não disparam o atalho. Esses continuam entrando pelo Importar CSV da fatura. No Android, dá para fazer o mesmo com MacroDroid ou Tasker lendo a notificação do Nubank e chamando este link.
